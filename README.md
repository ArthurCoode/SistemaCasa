# 🍽️ Sistema de Alimentos — PHP + Laravel

Meu primeiro projeto desenvolvido utilizando **PHP e Laravel**, com o objetivo de colocar em prática conceitos de desenvolvimento backend e frontend.

## 🚀 Sobre o projeto

O projeto consiste em um sistema CRUD para gerenciamento de alimentos, permitindo:

- ✅ Cadastrar alimentos
- ✏️ Editar alimentos
- 🗑️ Excluir alimentos
- 📋 Listar alimentos
- 🔄 Comunicação entre frontend e backend através de API

O projeto foi desenvolvido utilizando vídeos no YouTube como referência. Durante o desenvolvimento, fiz modificações e adaptações para entender melhor cada etapa e aprofundar meus conhecimentos.

## 🛠️ Tecnologias utilizadas

- PHP
- Laravel
- JavaScript
- Blade
- API REST
- MySQL
- Git
- GitHub

## 📚 O que aprendi

Durante o desenvolvimento, pude praticar conceitos como:

- Estrutura do Laravel
- MVC
- Models e Migrations
- Controllers
- Rotas
- APIs
- CRUD
- Integração entre frontend e backend
- JavaScript com requisições AJAX
- Manipulação de banco de dados
- Versionamento com Git

## 📌 Desenvolvimento

Todo o desenvolvimento foi dividido em etapas, e cada parte importante do projeto foi registrada através de **commits no GitHub**, permitindo acompanhar a evolução do sistema desde sua criação até os testes e correções finais.

## 🎯 Objetivo

Este projeto foi desenvolvido principalmente como forma de **aprendizado e prática**, sendo meu primeiro contato mais aprofundado com PHP e Laravel.

Foi uma experiência muito importante para continuar evoluindo como desenvolvedor e pretendo utilizar os conhecimentos adquiridos em projetos cada vez mais completos.
